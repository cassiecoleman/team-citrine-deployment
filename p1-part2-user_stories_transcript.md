# Ultra Ride-Sharing App -- User Story Generation

## Project Context

We are building **Ultra**, a ride-sharing app designed for underserved
rider demographics.

### Core User Groups

-   **Parents (especially single parents)** who need child-safe,
    reliable rides for their kids\
-   **Car-free commuters** who depend on rides to get to work daily\
-   **Budget-conscious riders** who want predictable, affordable pricing

------------------------------------------------------------------------

# Prompt to AI

Generate a **feature-complete set of ten user stories** organized under
epics.

Each story should follow the format:

> **"As a \[type of user\], I want \[goal\] so that \[benefit\]."**

The stories should cover:

-   Ride booking / scheduling
-   Safety features
-   Pricing / payments
-   Driver management
-   Real-time tracking
-   Notifications
-   Account management
-   Any other essential features

about user stories.

-   What is a **popular template for user stories**, and why is the

> action / benefit**.

# Design Decisions Behind the User Stories

## 1. Who / What / Why Template

Every user story follows the format precisely.

-   **Who** identifies a specific demographic
-   **What** describes a concrete user action
-   **Why** explains the benefit tied to real user needs

Stories do **not** use generic "user" roles.\
They reference **real personas identified in user discovery**.

------------------------------------------------------------------------

## 2. Epic Structure

The stories are grouped under epics that cover all required feature
areas.

  Epic                        Stories
  --------------------------- ------------
  Ride Booking & Scheduling   US01, US02
  Safety Features             US03, US04
  Pricing & Payments          US05, US06
  Driver Management           US07

  Notifications               US09

## 3. Alignment With User Personas

Each story maps directly to one of Ultra's **three core personas**.

### Single Parents

Focus areas:

-   Child safety
-   Driver verification
-   Multiple rider profiles
-   SMS alerts

### Car-Free Commuters

Focus areas:

-   Advance booking
-   Reliable rides to work
-   Real-time ride tracking

### Budget-Conscious Riders

Focus areas:

-   Predictable pricing
-   Weekly ride packages
-   Fare splitting
